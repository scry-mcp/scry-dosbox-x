#   It can say a count MOVED. That is what it is for, and it fires in BOTH directions --
#   a count that ROSE against an unchanged file means the reader has begun reading
#   something that is not a symbol, which is the quieter half.
#   It CANNOT say a count is CORRECT. The first time a project's row is written,
#   whatever the reader says becomes the expectation, so a reader that was already wrong
#   stays wrong and the sweep goes on agreeing with it. Closing that is reading the map,
#   by a person, once -- exactly as blessing any golden is.
